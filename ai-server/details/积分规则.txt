萌萌币（积分）与 AI 计费说明
================================

一、萌萌币是什么
萌萌币是论坛内的积分，主要用于抽奖、表情包商店等，与「会员 AI 额度」是两套体系。

常见获取方式：
- 每日签到：签到页领取，连续签到可能有额外奖励
- 发帖与互动：发帖、被点赞、收藏等（以活动公告为准）
- 抽奖：消耗萌萌币参与，中奖可到账
- 商城与活动：限时赠送等

查看余额：个人中心、签到页可查看当前萌萌币与流水。
注意：萌萌币一般不可转让；异常刷分可能被处理。


二、AI 功能怎么计费（重要）
--------------------------------
1）所有登录用户（含非会员）
   - 默认按「次数 / 日额度」使用 AI，不扣萌萌币
   - 非会员：看板娘对话等有每日次数上限（Redis 计数）
   - 非会员写作：DeepSeek Flash 等按每日写作次数（ai_usage_daily）
   - 用量展示：优先使用大模型 API 返回的 usage（prompt_tokens / completion_tokens），由厂商统计，论坛侧不手算 token
   - 响应耗时：ai-server 记录 latency_ms 一并返回

2）有效会员（vip_tier > 0 且未过期）
   - 默认不扣萌萌币，按会员档位消耗「每日次数 + 本周期 Token 配额」
   - 会员中心按模型分别展示（通义 / DeepSeek / Gemini / Claude 等），不再合并为一条「高级大模型写作」
   - 仍会把 token 用量、耗时写入 forum_ai_usage_log 便于审计
   - 前端展示计费方式：「会员额度」

3）会员额度将用尽时，可选用萌币扣费
   - 当当前所选模型配额使用率 ≥ 95% 时，小萌输入区模型选择右侧可出现「使用萌币积分」
   - 开启前会弹窗提示：按实际 token 扣萌币，费用可能较高
   - 开启后本次请求走萌币扣费（billingMode=points），不再占用该次会员额度

4）「（用量为估算）」何时出现
   - 仅当流式结束仍未拿到厂商 usage（input/output 均为 0）时标记为估算
   - 有厂商 token 时不显示该提示，也不再用固定的 2000/1000 占位数字


三、前端展示（小萌对话 / 画图）
每条 AI 回复时间左侧会显示可读摘要，例如：
   用时 1.2 秒 · 阅读 320 token · 回复 85 token · 会员额度
或（萌币模式）：
   用时 800 毫秒 · 阅读 200 token · 回复 60 token · 扣 3 积分


四、会员额度查看
开通 PRO/MAX 后可在「会员中心」查看各模型今日已用 / 上限（DeepSeek、通义、Gemini、Claude、生图等，按模型分行）。
若库中仍有历史配置 advanced_llm，界面会自动隐藏该合并行；可执行 migrate-vip-quota-display-20260604.sql 清理。

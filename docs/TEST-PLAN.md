## 0. 怎么用这份文档

### 0.1 环境准备

按 README 顺序起环境，任一步失败先解决再往下走，不要带着半截环境测：

```powershell
.\deploy\scripts\dev-compose.ps1 up -d   # Nacos / MySQL / Redis / RabbitMQ / PostgreSQL / ffmpeg
.\scripts\init-db.ps1                    # 仅限空库
.\deploy\scripts\sync-nacos.ps1          # 推配置并回读校验
cd forum-vue\front; npm install; npm run dev
# IDEA 启动 gateway、auth、content、im、game、economy、ai
cd ai-server; python main.py
```

> **有数据的库禁止跑 `init-db` / `reset-db`。** 迁移 `V20260903__vip_order_fields.sql` 本地已执行过，不要重复跑（`ADD COLUMN` 不幂等）。

### 0.2 测试账号矩阵（建议提前造好）

| 代号 | 用途 | 关键前置 |
| --- | --- | --- |
| **U-GUEST** | 未登录游客 | 无 token |
| **U-NEW** | 全新注册号 | 无任何成功订单，首购资格在 |
| **U-FREE** | 免费档老号 | 有历史成功订单，首购资格已用掉 |
| **U-PRO** | PRO 会员 | 剩余 > 20 天 |
| **U-PRO-1D** | PRO 将到期 | 剩余 ≤ 1 天，验升级差价与白嫖防线 |
| **U-MAX** | MAX 会员 | 验降级拒绝 |
| **U-TRIAL** | 体验卡得来的 PRO | 无 PRO 购买流水，验升级定价体系回退 |
| **U-B / U-C** | 对手方 | 私信、群聊、对局、牵线、举报的另一侧 |
| **U-BAN** | 被封禁号 | `state=1` |

多用户场景（私信 / 群聊 / 对局 / 观战 / 牵线）**必须用两个隔离会话**（不同浏览器或无痕窗口），同一浏览器切账号会串 token 与 WS 连接。

### 0.3 每条用例顺带看的四件事

1. **控制台无红错**（前端 console + 后端 stderr）。
2. **界面无破版**：布局不错位、控件不重叠（本项目**没有暗色模式**，不需要切主题验证）。
3. **traceId 串得起来**：响应里的 `X-Trace-Id` 能在下游服务日志 grep 到。
4. **未登录拦截在 UI 入口**生效，后端 401 只是兜底。

## 1. 风险地图：优先测这些

来自提交历史与已知未验证项，**本轮测试的重点**：

| 风险区 | 为什么 | 用例组 |
| --- | --- | --- |
| 会员订单与支付全链路 | 整套下单 / 回调 / 发货**一次真实运行都没跑过** | `VIP-*` |
| Feign 默认读超时 60s → 5s | 跨域调用可能莫名 5 秒超时；走 AI 的四个客户端本应保留 60s | `OBS-01~04` |
| MQ 监听器工厂被自定义 Bean 覆盖 | `acknowledge-mode: manual` 可能没保住，会重复消费 / 不 ack | `OBS-05~08` |
| `tierSnapshot` 去掉行锁 | 会员档位 / 配额并发读可能不对 | `VIP-40~43` |
| OSS 待定区转正 | 上传只落 `_pending/`，漏改绑定点会被生命周期删掉 | `FILE-*` |
| 看板娘牵线 | 五条隐私约束任意一条破了功能就作废 | `MAS-30~44` |
| 举报管线（帖 / 评论 / 弹幕 / 私信 / 歌曲共用） | 阈值、占位任务号改写、失实停权 | `MOD-*` |
| Sentinel 异常比例熔断 | 此前从未真正触发过，改法很微妙 | `OBS-10~14` |
| 通知跳转 `related_id` | 只有帖子审核类是帖子 ID，其余类型会跳错 | `IM-42~43` |
| traceId 跨 RabbitMQ | 新补的一段，最容易验证也最容易漏 | `OBS-20~23` |

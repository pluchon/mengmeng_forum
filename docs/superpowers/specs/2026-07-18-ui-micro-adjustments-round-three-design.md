# UI 微调第三轮设计

## 范围

本轮只处理用户列出的八项微调，不新增数据表、业务状态或接口。现有成长记录分页接口继续复用，仅把前后端默认页大小统一为 10。

## 交互与视觉

- 抽奖页左卡仅保留抽奖记录入口、硬保底状态和活动选择；移除余额、十连差额及进度条。三张主卡继续由同一网格拉伸到底部对齐。奖池奖品卡不再展示单项概率。
- 群消息举报继续使用现有提交接口；弹窗标题居中加粗，不再展示说明句，输入框从一行高度随内容增长，最多六行后内部滚动。
- 公告与活动入口从头像菜单迁入首页左侧快速入口，复用现有 `showAnnouncement` 动作。
- 行为验证码只保留右上角关闭入口。关闭时必须拒绝当前验证 Promise，让登录页 `finally` 结束加载状态。
- 未登录提示只显示居中加粗标题和一枚整行红色登录按钮，关闭入口仍使用右上角图标。
- AI 搜索使用静态金色镶边；一段白色高光以较慢速度顺时针沿边缘运行，并为减少动态效果偏好关闭动画。
- 成长记录从页面主体移入弹窗。入口放在等级卡 XP 数值右侧；弹窗以名称、来源、时间、经验四列展示，明确处理加载、错误、无权限和空数据状态，后端每页返回 10 条。

## 风险控制

- 不修改认证接口或验证码服务，只修复前端取消分支的 Promise 生命周期。
- 不改变抽奖概率计算与业务规则，只隐藏奖品卡上的概率文案。
- 不修改成长记录数据模型与查询条件，只调整默认分页大小和展示位置。

# 问答帖与最佳答案 P0 PRD

> 状态：已完成并通过本地验收（2026-07-13）

## 1. 目标

在复用现有帖子、一级评论和审核链路的前提下，形成“发起问题 → 社区回答 → 作者采纳 → 问题解决”的最小闭环。P0 不引入积分悬赏、独立答案表、投票或申诉流程。

## 2. 已交付范围

- 发布页仅展示“帖子类型”标题和“普通帖子 / 问答帖子”两个选择按钮；编辑已有帖子时不允许变更类型。
- 问答帖继续复用现有板块、标签、图文/视频、草稿和异步审核流程。
- 首页不新增问答专区或类型筛选；普通帖与问答帖继续使用既有热度帖、新帖混排逻辑和同一套卡片骨架。
- 问答卡片不展示文字类型标签，通过底部淡色问号背景、解决状态和纯文字“xx回答”与普通帖形成轻量区分。
- 问答状态仅包含：`待解决`、`已解决`、`已关闭`。
- 现有一级评论作为回答，问题作者可采纳一条有效回答作为最佳答案。
- 详情页不重复展示独立最佳答案卡片，仅将被采纳的一级回答放大为浅绿色背景并在右上角标记“最佳答案”；其楼中楼回复保持普通背景。
- 详情页不展示帖子类型；问题状态放在作者栏右侧，不再提供“查看最新点赞用户”功能及前后端接口。
- 问题作者可关闭尚未解决的问题；关闭后保留浏览、点赞和收藏，但禁止继续回答。
- 被采纳回答删除后，最佳答案引用被清除，问题自动回到“待解决”。
- 深色模式已覆盖发布类型选择、首页问答标记、详情状态、最佳答案和关闭提示。

## 3. 已确认业务规则

### 3.1 权限

- 发帖和回答继续复用“正式用户才可创作”的既有权限。
- 用户身份只从认证上下文读取，不接受前端传入作者 ID。
- 仅问题作者可以采纳答案或关闭问题。
- 最佳答案的公开查询仍受帖子发布状态和可见性约束。

### 3.2 状态流转

| 当前状态 | 操作 | 目标状态 | 约束 |
|---|---|---|---|
| 待解决 | 采纳有效回答 | 已解决 | 一题最多一条最佳答案 |
| 待解决 | 作者关闭 | 已关闭 | 已存在最佳答案时不可关闭 |
| 已解决 | 删除已采纳回答 | 待解决 | 清除最佳答案引用 |
| 已关闭 | 回答 | 不变 | 后端拒绝写入 |

- P0 中已关闭问题不能重新打开。
- 重复采纳同一回答和重复关闭按幂等结果处理。
- 采纳、关闭、删除已采纳回答均通过事务和条件更新保护并发一致性。

## 4. 数据模型

复用 `article` 和 `article_reply`，仅在 `article` 增加：

| 字段 | 类型 | 含义 |
|---|---|---|
| `article_type` | `TINYINT NOT NULL DEFAULT 0` | 0 普通帖，1 问答帖 |
| `question_status` | `TINYINT NULL` | 0 待解决，1 已解决，2 已关闭；普通帖为空 |
| `accepted_reply_id` | `BIGINT NULL` | 已采纳的一级回答 ID |

索引：`(article_type, question_status, status, delete_state, update_time)`，为后续按问答状态检索和运营查询保留；P0 首页不按类型过滤。

## 5. 接口

| 方法 | 路径 | 鉴权 | 用途 |
|---|---|---|---|
| `POST` | `/articleQuestion/acceptAnswer` | 必须登录 | 作者采纳最佳答案 |
| `POST` | `/articleQuestion/close` | 必须登录 | 作者关闭待解决问题 |
| `GET` | `/articleQuestion/acceptedAnswer` | 可选登录 | 查询最佳答案 |
| `GET` | `/board/selectBoardListByBoardIdWithPage` | 可选登录 | 沿用现有统一帖子流，不增加问答筛选参数 |

请求使用独立 DTO，响应使用 VO；Controller 只负责参数接收、调用 Service 和返回结果。

## 6. 异常与空状态

- 普通帖调用问答接口：返回“不是问答帖”。
- 非作者采纳或关闭：返回无权限。
- 回答不存在、已删除、被禁用或不属于该问题：禁止采纳。
- 已关闭问题提交回答：后端拒绝，不能只依赖前端禁用。
- 无最佳答案时查询返回空数据，详情页不渲染“最佳答案”标记和浅绿色背景。
- 统一帖子流无结果时展示通用空状态。

## 7. P0 非目标

- 萌币悬赏、冻结、结算、退款；
- 多答案、答案投票、申诉和仲裁；
- 重新打开已关闭问题；
- 独立答案编辑器或新的评论体系；
- AI 自动选答案或生成答案。

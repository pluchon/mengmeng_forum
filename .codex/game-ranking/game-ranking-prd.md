## 1. 背景

游戏中心当前已有五子棋、井字棋、俄罗斯方块 PK。后续还计划新增坦克大战 PK、贪吃蛇 PK。

排位系统第一版不做复杂隐藏分，也不按游戏拆多套段位。用户只理解一套段位即可，不同游戏只通过结算权重体现竞技价值差异。

## 2. 目标

- 所有真人 PK 游戏共用一套段位名称。
- 对局结束后展示本局排位分变化。
- 不同游戏按权重影响加减分。
- 只过滤明显没有实质内容的对局。
- 页面展示当前段位、排位分、距离下一小段进度。

## 3. 非目标

- P0 不做赛季、赛季结算、赛季奖励。
- P0 不做复杂 MMR、隐藏分、晋级赛。
- P0 不做全局防刷画像。
- P0 不因为高手赢得快而降低收益。
- P0 不因为对手重复或异常结束额外惩罚。
- P0 不让单人游戏、AI 对局、观战、聊天影响排位。

## 6. 结算规则

### 6.1 基础胜负分

| 结果 | 基础变化 |
|---|---:|
| 胜利 | +12 |
| 失败 | -8 |
| 平局 | 0 |
| 逃跑 / 超时判负 | -12 |

说明：

- 平局记入战绩，但不加不扣排位分。
- 逃跑、断线、超时不再额外判断动机，只按判负结果处理。
- 对局结果必须由后端结算服务判定，前端只展示结果。

### 6.2 对手强弱修正

按双方当前小段位差修正基础分。

| 对手情况 | 胜利基础分 | 失败基础扣分 |
|---|---:|---:|
| 对手高 2 个小段以上 | +16 | -5 |
| 对手高 1 个小段 | +14 | -6 |
| 同段附近 | +12 | -8 |
| 对手低 1 个小段 | +10 | -9 |
| 对手低 2 个小段以上 | +8 | -11 |

### 6.3 游戏权重

| 游戏 | 权重 | 说明 |
|---|---:|---|
| 五子棋 | 1.0 | 标准排位价值 |
| 井字棋 | 0.6 | 局短、平局多，降低分值波动 |
| 俄罗斯方块 PK | 0.85 | 节奏快，略低于标准分 |
| 坦克大战 PK | 待定 | 后续接入时再定 |
| 贪吃蛇 PK | 待定 | 后续接入时再定 |

### 6.4 连胜奖励

| 连胜 | 额外加分 |
|---|---:|
| 2 连胜 | +1 |
| 3 连胜 | +2 |
| 4 连胜 | +3 |
| 5 连胜及以上 | +4 |

规则：

- 失败后连胜清零。
- 平局不增加连胜。
- P0 不做连败补偿。

### 6.5 对局质量门槛

本地策略只判断是否有实质内容，不判断玩家动机。

| 游戏 | P0 有效门槛 |
|---|---|
| 五子棋 | 黑白双方各至少 4 手 |
| 井字棋 | 只要产生结果即有效 |
| 俄罗斯方块 PK | 双方最高分达到 300 |

说明：

- 未达到门槛时，只更新必要状态，不加不扣排位分。
- 五子棋后续接 AI 后，再判断明显故意送棋、无防守等复杂质量问题。

## 7. 结算公式

P0 公式：

```text
胜利排位分 = 对手强弱后的胜利基础分 × 游戏权重 + 连胜奖励
失败排位分 = 对手强弱后的失败基础扣分 × 游戏权重
```

约束：

- 最终分数不能低于 1000。
- 单局加分不超过 +20。
- 单局扣分不低于 -15。
- 结算必须幂等，避免重复加减分。

## 8. 页面展示

### 8.1 游戏匹配页

展示：

- 当前段位。
- 当前排位分。
- 段位进度条。
- 距离下一小段还差多少分。
- 当前游戏在线或房间信息。

### 8.2 对局记录

展示：

- 胜负结果。
- 当前用户真实排位分变化。
- 结束原因。
- 结束时间。

### 8.3 排行榜

排行榜按游戏维度展示：

- 排名。
- 用户头像与昵称。
- 统一段位。
- 排位分。
- 胜率。
- 总局数。

## 10. 验收标准

- 所有已接入真人 PK 游戏展示统一段位名。
- 五子棋、井字棋、俄罗斯方块 PK 使用不同结算权重。
- 未达到本地质量门槛的对局不加不扣排位分。
- 匹配页能展示段位进度条。
- AI 对局、单人模式、观战、聊天不影响排位。
- 排行榜能按排位分展示统一段位。

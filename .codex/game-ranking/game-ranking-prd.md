# 游戏中心排位系统 PRD

> 文档版本：V0.1
>
> 当前状态：规划中
>
> 适用范围：游戏中心真人 PK 游戏，包括五子棋、井字棋、俄罗斯方块 PK，以及后续坦克大战 PK、贪吃蛇 PK。

## 1. 背景

当前游戏中心已经有五子棋、井字棋、俄罗斯方块单人和俄罗斯方块 PK。后续还计划新增坦克大战 PK、贪吃蛇 PK。

现有 `game_user_profile` 已按 `gameCode` 保存玩家在单个游戏下的积分、胜负场次和当前状态，适合作为第一版排位系统的数据底座。

本需求只定义排位系统第一阶段能力，不实现代码。

## 2. 目标

- 为每个真人 PK 游戏提供独立段位。
- 让玩家能看到当前段位、距离下一小段还差多少分、排行榜段位展示。
- 对局结束后展示本局排位分变化。
- 升段或掉段时给出明确提示。
- 规则保持简单，但不能像纯玩具分数。

## 3. 非目标

- P0 不做全游戏统一总段位。
- P0 不做赛季、赛季结算、赛季奖励。
- P0 不做复杂 MMR、隐藏分、晋级赛。
- P0 不做排位皮肤、称号奖励、段位边框发放。
- P0 不让单人游戏进入排位。
- P0 不让 AI 对局、练习局、观战、聊天影响排位。

## 4. 适用游戏

排位只适用于真人 PK 游戏。

| 游戏 | 是否进入排位 | 说明 |
|---|---|---|
| 五子棋 | 是 | 真人匹配局计入 |
| 井字棋 | 是 | 真人匹配局计入 |
| 俄罗斯方块 PK | 是 | 真人 PK 局计入 |
| 坦克大战 PK | 是 | 后续接入 |
| 贪吃蛇 PK | 是 | 后续接入 |
| 俄罗斯方块单人 | 否 | 只做排行榜和历史记录 |
| AI 对局 | 否 | 可进练习战绩，不影响排位 |

## 5. 段位设计

### 5.1 分数区间

每个大段 300 分，每个大段内部 3 个小段，每小段 100 分。

| 分数区间 | 段位 |
|---:|---|
| 1000 - 1099 | 青铜 III |
| 1100 - 1199 | 青铜 II |
| 1200 - 1299 | 青铜 I |
| 1300 - 1399 | 白银 III |
| 1400 - 1499 | 白银 II |
| 1500 - 1599 | 白银 I |
| 1600 - 1699 | 黄金 III |
| 1700 - 1799 | 黄金 II |
| 1800 - 1899 | 黄金 I |
| 1900 - 1999 | 铂金 III |
| 2000 - 2099 | 铂金 II |
| 2100 - 2199 | 铂金 I |
| 2200 - 2299 | 钻石 III |
| 2300 - 2399 | 钻石 II |
| 2400 - 2499 | 钻石 I |
| 2500+ | 大师 |

### 5.2 初始与保护

- 初始排位分：1000。
- 最低排位分：1000。
- 青铜 III 失败最多扣到 1000。
- 掉段按分数自然发生，不做保段卡。
- P0 不做晋级赛。

### 5.3 游戏化展示

底层段位规则统一，但不同游戏可以展示不同主题称号。

| 游戏 | 示例称号 |
|---|---|
| 五子棋 | 黄金棋士 II |
| 井字棋 | 黄金先手 II |
| 俄罗斯方块 PK | 黄金堆叠者 II |
| 坦克大战 PK | 黄金车长 II |
| 贪吃蛇 PK | 黄金猎食者 II |

称号只影响展示，不影响结算。

## 6. 加分规则

### 6.1 基础胜负分

| 结果 | 基础变化 |
|---|---:|
| 胜利 | +12 |
| 失败 | -8 |
| 平局 | 0 |
| 逃跑 / 超时判负 | -12 |

说明：

- 井字棋平局较多，P0 统一按 0 分处理，避免刷分。
- 五子棋如果后续确认平局极少，可单独讨论是否给 +1。
- 对局结果必须由后端结算服务判定，前端只展示结果。

### 6.2 对手强弱修正

按双方当前小段位差修正分数。

| 对手情况 | 胜利加分 | 失败扣分 |
|---|---:|---:|
| 对手高 2 个小段以上 | +16 | -5 |
| 对手高 1 个小段 | +14 | -6 |
| 同段附近 | +12 | -8 |
| 对手低 1 个小段 | +10 | -9 |
| 对手低 2 个小段以上 | +8 | -11 |

### 6.3 连胜奖励

| 连胜 | 额外加分 |
|---|---:|
| 2 连胜 | +1 |
| 3 连胜 | +2 |
| 4 连胜 | +3 |
| 5 连胜及以上 | +4 |

规则：

- 失败后连胜清零。
- 平局不增加连胜。
- P0 不做连败补偿。

### 6.4 防刷限制

- 同一对手 30 分钟内重复对局，第 2 局开始胜利收益减半。
- 同一对手当天最多前 3 局计入完整排位分。
- 对局时长或有效操作数低于门槛时，不按正常胜利加分。
- 主动退出、断线超时判负，扣分高于普通失败。
- 表现数据不影响排位分，只用于页面展示。

建议最低门槛：

| 游戏 | 最低有效门槛 |
|---|---|
| 五子棋 | 双方合计至少 6 手 |
| 井字棋 | 双方合计至少 3 手 |
| 俄罗斯方块 PK | 对局至少 30 秒 |
| 坦克大战 PK | 对局至少 30 秒 |
| 贪吃蛇 PK | 对局至少 30 秒 |

## 7. 结算公式

P0 公式：

```text
本局排位分变化 = 对手强弱后的胜负分 + 连胜奖励 - 防刷惩罚
```

约束：

- 最终分数不能低于 1000。
- 单局加分不超过 +20。
- 单局扣分不低于 -15。
- 结算必须幂等，避免重复加减分。

## 8. 页面展示

### 8.1 游戏匹配页

展示：

- 当前段位。
- 当前排位分。
- 距离下一小段还差多少分。
- 近期胜率。
- 连胜状态。

### 8.2 对局结算页

展示：

- 胜负结果。
- 本局排位分变化。
- 当前段位变化。
- 晋级成功 / 段位下降提示。
- 本局表现数据。

表现数据只做趣味展示，例如：

- 本局 MVP。
- 极限翻盘。
- 最高连击。
- 最后一手制胜。

这些数据不参与排位分计算。

### 8.3 排行榜

排行榜按游戏独立展示：

- 排名。
- 用户头像与昵称。
- 段位。
- 排位分。
- 胜率。
- 总局数。

## 9. 阶段规划

### P0：基础排位

- 分游戏独立段位。
- 100 分一个小段，300 分一个大段。
- 基础胜负分。
- 对手强弱修正。
- 连胜奖励。
- 防刷限制。
- 匹配页、结算页、排行榜展示段位。

### P1：体验增强

- 游戏主题称号。
- 最近 10 场排位趋势。
- 历史最高段位。
- 更多结算文案，例如“晋级成功”“距下一段还差 12 分”。

### P2：赛季与荣誉

- 赛季榜。
- 赛季重置。
- 赛季结算称号。
- 游戏中心代表段位。
- 段位徽章或边框奖励。

## 10. 验收标准

- 每个真人 PK 游戏能独立展示当前段位。
- 对局结束后能正确计算排位分变化。
- 升段、掉段、保底 1000 分逻辑正确。
- AI 对局、单人模式、观战、聊天不影响排位。
- 重复对局防刷规则生效。
- 排行榜能按排位分展示段位。
- 结算重复触发时不会重复加减分。

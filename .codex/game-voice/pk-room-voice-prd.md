# PK 房间语音聊天 PRD

> 文档版本：V0.2
>
> 当前状态：当前阶段取消
>
> 适用范围：游戏中心所有 PK 房间。

## 1. 结论

当前阶段不再实现游戏对战内语音聊天。

原因是 PK 房间语音需要同时维护游戏房间状态、WebRTC 信令、麦克风权限、跨页面资源释放和对局生命周期，维护成本高于当前阶段收益。

## 2. 当前阶段规则

- 游戏中心 PK 房间不展示语音入口。
- 游戏房间继续保留文字聊天。
- 群聊语音和私聊语音属于论坛全局语音能力，可以在游戏中心和具体游戏页面继续挂起使用。
- 进入登录、注册、忘记密码等非登录态页面，已挂起的论坛语音聊天需要自动退出。

## 3. 非目标

- 不做双人 PK 语音。
- 不做观战语音。
- 不做游戏房间语音信令。
- 不在游戏 WebSocket 中增加语音消息类型。
- 不新增游戏语音数据库表。

## 4. 后续再评估条件

后续如果重新评估，需要先有稳定 TURN 兜底、统一语音 SDK 封装和明确的运维资源预算，再单独重开 PRD。
